# CNN on MNIST and SigmoidNeuron re-runs, 2026-10-14

`CNN_Identify_the_Digits_(MNIST).ipynb` was executed top to bottom on a CPU with its **original training settings, unreduced**. An earlier audit judged it too slow for the 20-minute limit; timing it showed otherwise (about 13 ms per training step at batch size 10), so no reduction was needed.

## Settings (as written in the notebook's training cell)

| Item | Value |
|---|---|
| Data | MNIST via `keras.datasets.mnist`: 60,000 training images, 10,000 test images, pixels scaled to 0..1 |
| Architecture (unchanged) | Conv2D 32 (3x3) - Conv2D 64 (3x3) - MaxPool 2x2 - Dropout 0.25 - Flatten - Dense 256 - Dropout 0.5 - Dense 10 softmax; 2,380,938 parameters |
| Optimiser, loss | Adam (defaults), categorical cross-entropy |
| Training | `epochs=5`, `batch_size=10` (6,000 steps per epoch, 30,000 in total), `validation_data=(x_test, y_test)` |
| Seeds | none (the notebook sets none), `PYTHONHASHSEED=0` only |

## Hardware and software

AMD Ryzen 7 5800X (8 cores, 16 threads), 32 GB RAM, Windows 11, no GPU used. Python 3.11.9, TensorFlow 2.15.1, Keras 2.15.0, NumPy 1.26.4, scikit-learn 1.5.2, matplotlib 3.9.2, nbconvert 7.16.4 (versions as in `requirements.txt`).

## Command


## SigmoidNeuron
